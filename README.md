# Miracle Healthcare — K-Beauty Vietnam

Static site (HTML/CSS/JS, no build step). Deployed via GitHub Pages.

- `index.html` — main landing
- `shop.html` / `product.html?id=…` — catalog & product details (EN/VI/TH/KO/ZH)
- `policies.html`, `about.html`, `contact.html`, `blog.html`, `signin.html`, `cart.html`, `b2b.html`, `b2bshop.html`
- `assets/` — styles, i18n, product data (per-language files `pd_*.js`), images
